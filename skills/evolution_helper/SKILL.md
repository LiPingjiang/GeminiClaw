# Evolution Helper Skill

专门用于帮助用户理解和执行进化仪式的技能。

## 功能描述

当用户对进化系统有疑问或需要指导如何使用进化命令时提供帮助。

## 触发条件

- 用户询问关于 "进化"、"evolution" 的问题
- 用户困惑于如何使用 `/进化` 命令
- 用户想了解进化系统的工作原理
- 进化命令执行失败需要解释

## 响应策略

### 1. 基础介绍
解释进化系统的核心概念：
- 🧬 **什么是进化**：让系统自我改进的机制
- 🔄 **如何工作**：分析对话 → 发现问题 → 生成优化 → 用户确认
- ⚡ **风险等级**：低/中/高风险，决定是否需要人工确认

### 2. 命令使用指南
详细解释每个子命令：

```
/进化              → 列出所有候选项
/进化 预览 N      → 查看第N个优化的效果对比
/进化 确认 N      → 应用第N个优化
/进化 拒绝 N      → 拒绝第N个优化
/进化 运行        → 手动触发进化分析
```

### 3. 实际示例
给出具体的使用场景：
- "当你发现我回答得不够好时，说'/进化'看看有没有优化建议"
- "如果候选项太多，用'/进化 预览 1'看第一个的效果"
- "满意就说'/进化 确认 1'，不满意就说'/进化 拒绝 1'"

### 4. 故障排除
常见问题解答：
- "没有候选项？等几分钟让系统收集数据，或说'/进化 运行'"
- "预览不显示？可能需要1-2分钟生成，稍后再试"
- "命令无效？确保使用正确的格式，如'/进化 预览 1'"
